## 2024-05-24 - Auto-submit Patterns for Tkinter
**Learning:** Traditional desktop interfaces often rely on explicit "submit" buttons, which feels clunky to users accustomed to modern web interfaces where dropdowns auto-update and Enter keys submit forms.
**Action:** Always bind `<<ComboboxSelected>>` to dropdowns and `<Return>` to single-line text inputs to reduce required clicks and create a smoother, web-like interaction pattern in desktop apps.
