## 2026-04-24 - Auto-updating UI and Keyboard Accessibility in Tkinter
**Learning:** Users expect dropdown menus to auto-update content upon selection without needing an explicit "Update" button, and text fields should support pressing the Enter key for submission rather than forcing a button click. Implementing this in Tkinter requires explicitly passing an optional `event=None` to callback functions so they can handle both direct button clicks and Tkinter event loop bindings like `<<ComboboxSelected>>` and `<Return>`.
**Action:** Always verify that input fields have standard keyboard accessibility bindings (like `<Return>`) and dropdown selections immediately trigger visual updates using `<<ComboboxSelected>>` when designing Tkinter UIs, and ensure the corresponding callback functions accept `event=None`.
