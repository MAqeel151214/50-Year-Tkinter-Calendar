## 2024-07-18 - Tkinter Auto-Update and Keyboard Submission
**Learning:** Desktop app users expect web-like interactions, such as combobox selections instantly updating the main display and pressing 'Enter' to submit forms without requiring a button click.
**Action:** Always bind `<<ComboboxSelected>>` for select menus and `<Return>` for text entries in Tkinter interfaces to reduce friction and improve accessibility for keyboard users.
