## 2026-04-29 - Tkinter Modern Web UX Patterns
**Learning:** Tkinter interfaces can feel archaic because they often require explicit button clicks for every action. Modern web patterns expect auto-updating dropdowns and Enter-key form submissions. By binding `<<ComboboxSelected>>` to dropdowns and `<Return>` to inputs, we can significantly improve the UX and make the desktop app feel more intuitive.
**Action:** Always check if explicit action buttons can be augmented or replaced by direct event bindings (like Enter key or selection changes) in Tkinter applications to reduce friction.
